# To-Do-List-fildza-
membuat sebuah web untuk mengisis To Do List dalam kegiatan sehari hari. dan juga ditambahkan fitur seperti search bar ( untuk mencari kegiatan yang tenggelam atau bertumpuk dengan kegiatan lain ), priority levels ( 3 pilihan tingkat kepentingan dengan icon yang berbeda’ ), tags ( menambahkan pilihan kategori untuk sekolah, pribadi , dan lainnya )
